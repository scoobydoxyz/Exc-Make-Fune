How the ranking works

One function scores every protocol from the snapshot figures alone. No protocol name is special-cased and no row is hand-picked. The page recomputes each row’s implied value from the same figures and checks it against the board figure, so the code and the data agree.

base = tvl_usd × 0.25

growthMult = 1 + clamp(change_7d, −60, +120) / 100 × 0.5

maturityMult = 0.6 + min(max(age_days, 0), 1095) / 1095 × 0.4

chainMult = 1 + 0.03 × min(max(chains − 1, 0), 4)

shareMult = 0.90 + 0.20 × categoryShare

implied = max(1, round(base × growthMult × maturityMult × chainMult × categoryMult × shareMult))

  • Base 0.25 — a protocol is first valued at a quarter of its TVL.
  • Growth — 7-day TVL change, clamped to −60%…+120%, moves the value by half its size.
  • Maturity — age since first listing (0–3 years) scales 0.6 → 1.0; unknown age counts as 365 days.
  • Chains — each extra chain beyond the first adds 3%, up to 4 extra chains.
  • Category — a category multiplier carried in the data; it never depends on a protocol name.
  • Category share — the protocol’s share of its category’s rankable pre-token TVL. The share multiplier runs 0.90 (no share) to 1.10 (the whole category), and stays 1.0 when the category is unknown or holds only one rankable protocol.

What implied value is: the value a token would carry if the protocol’s track record held as it stands — the entry’s own claim, not a market price. What it is not: a prediction that a token will launch, or when.
